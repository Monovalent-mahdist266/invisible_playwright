## ⚙️ Configuration settings

The application uses default settings that work for most websites. You can change these if you need specific results:

* Proxy settings: You can enter SOCKS5 addresses if you need to route traffic through different regions.
* Fingerprint randomization: This alters how your browser communicates its identity to servers. High settings offer more protection, while low settings offer more speed.
* Headless mode: You can run the browser without seeing it to save computer resources. Set this to off if you want to watch the browser work in real time.

## 🛠️ How to use the application

The program interface remains simple for daily tasks. Open the application folder and click the executable file. A window opens showing the browser status.

To perform a task, input your target URL in the address box. Press the Start button. The invisible engine loads the page. It manages all browser fingerprints and headers automatically. The status bar tells you if the connection stays stable.

The tool handles hCaptcha and reCAPTCHA prompts by mimicking human mouse movements and timing. You never have to solve these puzzles manually.

## 🧩 Browser fingerprinting and privacy

Websites collect data about your device to build a profile. They look at your screen resolution, installed fonts, and hardware IDs. Invisible Playwright swaps these values with random, valid options. This prevents sites from linking your current session to your previous visits.

The tool updates internal lists of browser fingerprints every week. This ensures your profile stays relevant and avoids detection as sites update their security logic.

## 🌐 Network and proxy support

Automation often triggers blocks if too many requests come from one IP address. This tool supports SOCKS5 proxies to distribute your traffic. You can add a list of proxy addresses in the network menu. The browser rotates through these addresses for each request. Use private proxies to ensure the highest success rate.

## 📋 Common troubleshooting

If you face issues, check these frequent solutions:

* Connection errors: Make sure your internet connection works. Verify that your firewall allows the application to send and receive data.
* Website blocks: If a page still blocks you, try changing the fingerprint profile in the settings menu.
* Memory usage: Close other web browsers while running this tool. Too many open tabs can slow down your system.
* Anti-virus alerts: Some security programs might flag automation tools. Add the application folder to your anti-virus exclusion list if the program fails to launch.
